Checking the address · فحص العنوان
Matching threat lists · مطابقة قوائم التهديدات
Opening the page in an isolated checker · فتح الصفحة في فاحص معزول
Asking the AI about what was found · سؤال الذكاء الاصطناعي عن النتائج

How it works: Rasid checks the address with its own rules, matches it against public threat lists (OpenPhish, URLhaus, Phishing Army), opens the page in an isolated server that only connects to public internet addresses and checks every redirect before following it, then sends the evidence to an AI model (via Netlify AI Gateway). Page content is treated as untrusted data; Rasid never submits forms or credentials. Before anything reaches the AI, Rasid removes query values, tokens, emails, long numbers and any username or password in the link. Do not paste private links that contain passwords or access tokens.

طريقة العمل: يفحص راصد العنوان بقواعده الخاصة، ويطابقه مع قوائم تهديدات عامة (OpenPhish وURLhaus وPhishing Army)، ثم يفتح الصفحة في خادم معزول لا يتصل إلا بعناوين الإنترنت العامة ويفحص كل تحويل قبل متابعته، ثم يرسل الأدلة إلى نموذج ذكاء اصطناعي (عبر Netlify AI Gateway). يُعامل محتوى الصفحة كبيانات غير موثوقة، ولا يرسل راصد أي نماذج أو بيانات دخول. قبل الإرسال للذكاء الاصطناعي يحذف راصد قيم الاستعلام والرموز والبريد والأرقام الطويلة وأي اسم مستخدم أو كلمة مرور في الرابط. لا تلصق روابط خاصة تحتوي على كلمات مرور أو رموز دخول.
